# 🔗 ShortyLink - Modern URL Shortener & Analytics

A lightweight, feature-packed client-side URL Shortener application built with HTML5, Tailwind CSS, and Vanilla JavaScript.

## ✨ Features
- ⚡ **Instant URL Shortening**: Generate custom aliases or random slugs.
- ⏳ **Expiration Controls**: Set links to expire in 1 min, 1 hour, 24 hours, 7 days, or never.
- 📊 **Real-time Analytics**: Track total links created, active links, and total click counter.
- 📱 **QR Code Generator**: Generate dynamic QR codes for any shortened URL.
- 🎯 **Interactive Redirection Simulator**: Safe link preview with a countdown interceptor.
- 💾 **Persistence**: All links and stats persist in browser `localStorage`.
- 📁 **Export Data**: Download your link history in `JSON` or `CSV` format.
- 🌙 **Dark/Light Mode**: Smooth theme toggling with preferred system scheme detection.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/shortylink.git
   ```
2. Navigate into the folder:
   ```bash
   cd shortylink
   ```
3. Open `index.html` directly in your web browser, or serve it using Live Server.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [FontAwesome 6](https://fontawesome.com/)
- **QR Code**: [QRCode.js](https://davidshimjs.github.io/qrcodejs/)
